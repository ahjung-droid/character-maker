# 🏢 슈피겐코리아 채용상담회 앱

서강대학교 채용박람회 부스용 웹앱입니다. 첫 화면에서 두 가지 메뉴로 나뉩니다.

1. **🏢 슈피겐코리아 소개 보기** — 태블릿 키오스크용 **카카오톡 챗봇 형태** 화면.
2. **🪪 나만의 사원증 만들기** — 성향 분석 & 직무 추천 테스트. 참가자 정보를
   입력하고(개인정보 수집 동의 포함) 11개의 질문에 답하면, 성향을 분석해 귀여운
   동물 캐릭터가 담긴 **나만의 사원증(PNG)**, 맞춤형 별명, 잘 맞는 **추천 직무**를
   보여줍니다.

## 🏢 슈피겐코리아 소개 보기 (태블릿 챗봇)

부스에 태블릿을 세워두고 지원자가 직접 터치하며 보도록 만든 화면입니다.
카카오톡 대화방처럼 생겼고, 봇이 한 글자씩 타이핑하듯 말을 걸어요.

```
슈피겐코리아가 궁금하니..?
아래 궁금한 항목들을 눌러봐.. 가능하면 다 보는 게 유용할 거야..
상담도 받고 가..
```

- 아래쪽 **퀵리플라이 버튼**을 누르면 내 말풍선(노란색)이 뜨고, 봇이 짧게 대꾸한 뒤
  해당 주제 내용을 카드형 말풍선으로 보내줍니다.
- 이미 본 주제는 `✓` 표시로 흐려지고, 9개를 다 보면 마무리 멘트가 나와요.
- 항상 하단에 **▶️ 유튜브 구독하기**(https://youtube.com/@spigenhr)와
  **🪪 사원증 만들러 가기** 버튼이 붙어 있습니다.
- 홈으로 나갔다 들어오면 대화가 처음부터 새로 시작돼 다음 지원자가 깨끗하게 씁니다.
- 버튼을 빠르게 연타해도 답변이 서로 취소되지 않아요. 요청은 큐에 쌓여 순서대로
  처리되고, 뒤에 대기 중인 요청이 있으면 타이핑 연출을 건너뜁니다.

### 📖 3막 스토리라인

주제가 평평하게 나열되지 않도록 **3막 구조**로 묶여 있습니다 (`STORY_ACTS`).

| 막 | 주제 |
|---|---|
| 1막 · 우리는 누구인가 | 🏆 어떤 회사야? · 📦 뭘 만들어? · 🌏 어디서 팔아? |
| 2막 · 우리는 이렇게 일해 | 💡 이렇게 일해 · 🤖 AI와 함께 일해 |
| 3막 · 너는 이렇게 합류해 | 🎓 채용연계형 인턴 · 💻 리모트 인턴십 · 📢 채용 공고 · 🎁 채용 상담 & 이벤트 |

흐름을 만드는 장치 두 가지:

1. **막별 묶음** — 퀵리플라이 버튼이 막 소제목 아래로 묶여 나옵니다. 한 막을 다 보면
   소제목에 `✓`가 붙어요.
2. **다음 이야기 버튼** — 각 카드 맨 아래의 `다음 이야기 · ○○ →` 버튼을 계속 누르면
   이야기가 순서대로 흘러갑니다. 이미 본 주제는 건너뛰고, 다 보면 사원증 만들기로 연결돼요.

한 막을 다 채우면 봇이 다음 막을 예고합니다 (순서대로 안 보고 아무거나 골라도,
그 막을 다 본 시점에 나와요):

```
1막 완료 → "여기까지가 우리가 누구인지야.. 이제 우리가 어떻게 일하는지 궁금하지..?"
2막 완료 → "일하는 방식은 여기까지.. 이제 진짜 중요한 거.. 어떻게 들어오는지 알려줄게.."
전체 완료 → "이제 다 봤네..! 부스에서 상담도 꼭 받고 가.."
```

### 💼 직무별 상세 (채용 공고)

채용 공고 카드의 직무표에서 **직무명을 누르면** 대화가 이어지며 상세 카드가 나옵니다.
내용은 `JOB_POSTINGS`에 있고, `SPIGEN_INTRO`의 `hiring` 항목 표에서
`{ name, job: 'JOB_POSTINGS 키' }` 로 연결해요. 상세가 없는 직무는 일반 텍스트로 표시됩니다.

현재 등록된 직무: 글로벌 이커머스 영업(인도) / 글로벌 이커머스 영업(해외마케팅팀) /
글로벌 SCM(인도) / 기구개발 / 테스트 엔지니어

`quote`는 기본적으로 "🎤 리더의 한마디"로 표시되고, `quoteLabel: '동료의 한마디'` 처럼
적어주면 그 문구로 바뀝니다.

### 🔧 콘텐츠 수정하기

- 내용 출처: `[채용상담회] 슈피겐코리아 소개` 구글 슬라이드 + 채용 포스터
- 콘텐츠는 `index.html`의 `SPIGEN_INTRO` 상수에 들어 있어, 슬라이드가 바뀌면
  이 배열만 수정하면 됩니다. 항목마다 다음을 지원해요:
  `title` / `summary` / `reply`(봇의 대꾸 멘트) / `sections`(본문·칩) /
  `stats`(숫자 카드) / `steps`(프로세스 단계) / `table`(직군 표) /
  `timeline`(연도별 국가) / `links`(버튼) / `image`(사진)

### 🖼 슬라이드 이미지 넣기

각 항목에 `image: 'images/파일명.png'` 한 줄만 추가하면 카드 안에 사진이 함께 나옵니다.

```js
{
  key: 'work',
  title: '근무 환경 & 복지',
  image: 'images/work-lounge.png',   // ← 이렇게 추가
  ...
}
```

구글 슬라이드 PDF에서 이미지를 추출해 저장소의 `images/` 폴더에 넣고,
위처럼 경로만 적어주면 됩니다. (아직 이미지는 넣지 않은 상태예요)

## ✨ 사원증 만들기 주요 기능

- 참가 전 **이름 / 학년 / 전공 / 이메일** 입력 + **개인정보 수집·이용 동의** 필수 체크
- 11개 질문(밸런스 게임 9문항 + 관심 직무 선택 1문항 + 신규 3문항)으로 성향·직무 성향 분석
- 6종의 동물 캐릭터(리트리버/너구리/쿼카/고양이/판다/토끼 등) 매칭 + **8개 직무 분야 추천** (1·2순위)
- 참가자마다 고유한 별명 자동 생성 (중복 방지)
- 업로드 사진 기반 **사원증 스타일 결과 카드 PNG** 다운로드 (사진이 카드 대부분을 채우고, 이름과 추천 직무의 팀명만 표기)
- 관리자 페이지(숨김 진입)에서 참가자 전체 관리
- 참가자 정보와 테스트 결과를 **구글 스프레드시트로 자동 전송** (Apps Script 연동)
- 결과 카드(PNG)를 참가자의 다운로드 여부와 무관하게 **구글 드라이브에 자동 저장 + 담당자 메일로 자동 발송** (사원증 제작용)
- 관리자용 JSON 데이터 내보내기 / 구글 시트 재동기화

## 🚀 사용 방법

`index.html` 파일을 브라우저에서 열면 바로 동작합니다.
별도의 서버나 빌드 과정이 필요 없어요.

## 🔑 관리자 접속 (숨김)

참가자 데이터는 구글 시트로 바로 들어가므로, 부스 화면에는 관리자 버튼을
**노출하지 않습니다.** 그래도 현장에서 결과를 확인해야 할 때가 있어
숨은 통로를 남겨뒀어요.

**왼쪽 상단 로고를 1.5초 안에 5번 연속 탭** → 4자리 비밀번호 입력

비밀번호는 `index.html` 상단의 `ADMIN_PASSWORD` 상수에서 변경 가능합니다.

## 📦 데이터 저장

참가자 결과는 브라우저의 localStorage에도 항상 저장되므로, 구글 시트 연동이
실패하거나 네트워크가 끊겨도 데이터가 유실되지 않습니다. (관리자 페이지에서
"🔄 구글 시트 다시 동기화" 버튼으로 재전송할 수 있어요.)

사진(얼굴 이미지)은 구글 시트나 외부 서버로 전송되지 않고, 결과 카드를
만들기 위해 이 브라우저의 localStorage에만 저장됩니다.

## 📊 구글 시트 연동 설정 (참가자 정보 자동 수집)

1. 새 구글 스프레드시트를 만듭니다.
2. 상단 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
3. `apps-script/Code.gs` 파일의 내용을 통째로 복사해 붙여넣고 저장합니다.
4. **배포 > 새 배포 > 유형 선택(웹 앱)**을 클릭합니다.
   - 실행 계정: **나(본인)**
   - 액세스 권한: **전체 허용(누구나)**
5. 배포 후 발급되는 웹 앱 URL을 복사합니다.
6. `index.html` 상단의 `GOOGLE_SHEET_WEB_APP_URL` 상수 값에 붙여넣습니다.

설정을 완료하면:
- 참가자가 정보 입력 + 동의 후 "다음"을 누르는 순간 **lead(리드) 단계**로 이름/학년/전공/이메일이 시트에 기록되고,
- 테스트를 끝까지 완료하면 같은 행이 **result(결과) 단계**로 업데이트되어 성향·직무 추천 결과까지 함께 저장됩니다.

`GOOGLE_SHEET_WEB_APP_URL`을 비워두면 기존처럼 localStorage에만 저장되고
구글 시트로는 전송되지 않습니다 (앱은 정상 동작).

## 🪪 사원증용 결과 카드 자동 저장 (기기 의존 없는 "무조건 저장")

브라우저에서 PNG를 직접 다운로드하는 기능("📥 카드 PNG로 저장" 버튼)은 카카오톡 인앱
브라우저 등 일부 환경에서 다운로드가 막힐 수 있어요. 이 문제와 무관하게 항상 데이터가
남도록, **테스트가 끝나는 순간 결과 카드 이미지를 자동으로 서버에 전송**해서:

1. 구글 드라이브의 `채용박람회 사원증 카드` 폴더에 `참가자ID.png`로 저장되고 (없으면 자동 생성),
2. `apps-script/Code.gs`의 `NOTIFY_EMAIL` 상수에 이메일을 넣어두면, 카드가 완성되는 즉시
   해당 주소로 PNG가 첨부된 메일이 자동 발송됩니다. (기본값은 `ahjung@spigen.com`으로 되어
   있으니 필요하면 바꿔주세요. 참가자가 아주 많다면 Gmail 일일 발송 한도에 걸릴 수 있어
   빈 문자열로 비워서 드라이브 폴더만 쓰는 것도 방법이에요)

이 경로는 참가자의 브라우저/기기 상태와 완전히 무관하게 동작해요 (참가자가 다운로드 버튼을
누르지 않아도, 심지어 인앱 브라우저처럼 다운로드가 막힌 환경이어도 서버로는 항상 전송됩니다).

이 기능을 처음 켤 때는 Apps Script 배포 시 **구글 드라이브·Gmail 접근 권한** 승인 팝업이 새로
뜰 수 있어요. 본인 계정으로 승인해주세요.

## ⚠️ 개인정보 수집 동의 문구에 대해

정보 입력 화면의 개인정보 수집·이용 동의 문구(`index.html`의 `CONSENT_TEXT`
상수)는 **예시 템플릿**입니다. 실제 채용박람회에서 사용하기 전에 반드시
사내 HR/법무 담당자의 검토를 받아 수집 항목, 이용 목적, 보유 기간 등을
실제 운영 정책에 맞게 수정해주세요.

## 💼 직무 추천 로직

- **"성향 분석 기반 추천 직무"**(1·2순위)는 밸런스 게임 문항 10개의 답변만으로
  계산합니다. 각 선택지가 성향 점수(동물 캐릭터용)와 직무 성향 점수(8개 직무
  분야용)를 함께 반영하고, 이 점수를 합산해 1·2순위를 뽑습니다. (`index.html`의
  `JOB_ROLES`, `calculateJobScores`, `matchJobs` 참고)
- 마지막 문항("가장 끌리는 직무 분야를 골라주세요")은 참가자가 **직접 고르는
  자기 선언적 관심사**로, 결과 화면에 "🙋 직접 고르신 관심 분야"로 별도 표시만
  하고 **위 추천 점수 계산에는 포함하지 않습니다** (`getInterestJob` 참고).
  처음에는 이 문항도 점수에 합산했었는데, 가중치가 너무 커서 추천 결과가
  "그냥 내가 고른 답 그대로" 나오는 문제가 있어 분리했습니다 — 이제는 성향
  분석 결과와 참가자의 자기 선언이 서로 다르게 나올 수 있고, 둘이 일치하면
  화면에 "성향 분석 결과와도 잘 맞아떨어져요!"라고 표시해줍니다.
- 기본 직무 분야 8개(마케팅/브랜드기획, 영업/해외영업, 상품기획/MD, 디자인,
  연구개발/품질, SCM·생산·물류관리, 경영지원, IT/데이터)는 일반 제조·유통사
  기준 예시이므로, 실제 채용 중인 직무에 맞게 `JOB_ROLES`와 관련 문항의
  `jobTraits` 값을 조정해 사용하세요.
