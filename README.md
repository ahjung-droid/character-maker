# 🌸 우리 회사 부캐 메이커 (채용박람회 에디션)

서강대학교 채용박람회 부스용 성향 분석 & 직무 추천 웹앱입니다.
참가자 정보를 입력하고(개인정보 수집 동의 포함) 11개의 질문에 답하면,
AI가 성향을 분석해 귀여운 동물 캐릭터, 맞춤형 별명, 그리고 잘 맞는
**추천 직무**까지 함께 보여줍니다.

## ✨ 주요 기능

- 참가 전 **이름 / 학년 / 전공 / 이메일** 입력 + **개인정보 수집·이용 동의** 필수 체크
- 11개 질문(밸런스 게임 9문항 + 관심 직무 선택 1문항 + 신규 3문항)으로 성향·직무 성향 분석
- 6종의 동물 캐릭터(리트리버/너구리/쿼카/고양이/판다/토끼 등) 매칭 + **8개 직무 분야 추천** (1·2순위)
- 참가자마다 고유한 별명 자동 생성 (중복 방지)
- 업로드 사진 기반 결과 카드 PNG 다운로드 (추천 직무 포함)
- 관리자 페이지(비밀번호 인증)에서 참가자 전체 관리
- 참가자 정보와 테스트 결과를 **구글 스프레드시트로 자동 전송** (Apps Script 연동)
- 결과 카드(PNG)를 참가자의 다운로드 여부와 무관하게 **구글 드라이브에 자동 저장 + 담당자 메일로 자동 발송** (사원증 제작용)
- 관리자용 JSON 데이터 내보내기 / 구글 시트 재동기화

## 🚀 사용 방법

`index.html` 파일을 브라우저에서 열면 바로 동작합니다.
별도의 서버나 빌드 과정이 필요 없어요.

## 🔑 관리자 접속

오른쪽 상단의 "관리자" 버튼 → 4자리 비밀번호 입력
비밀번호는 `index.html` 상단의 `ADMIN_PASSWORD` 상수에서 변경 가능합니다.

## 📦 데이터 저장

참가자 결과는 브라우저의 localStorage에도 항상 저장되므로, 구글 시트 연동이
실패하거나 네트워크가 끊겨도 데이터가 유실되지 않습니다. (관리자 페이지에서
"🔄 구글 시트 다시 동기화" 버튼으로 재전송할 수 있어요.)

사진(얼굴 이미지)은 구글 시트나 외부 서버로 전송되지 않고, 결과 카드를
만들기 위해 이 브라우저의 localStorage에만 저장됩니다.

## 📊 구글 시트 연동 설정 (참가자 정보 자동 수집)

1. 새 구글 스프레드시트를 만듭니다.
2. 상단 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
3. `apps-script/Code.gs` 파일의 내용을 통째로 복사해 붙여넣고 저장합니다.
4. **배포 > 새 배포 > 유형 선택(웹 앱)**을 클릭합니다.
   - 실행 계정: **나(본인)**
   - 액세스 권한: **전체 허용(누구나)**
5. 배포 후 발급되는 웹 앱 URL을 복사합니다.
6. `index.html` 상단의 `GOOGLE_SHEET_WEB_APP_URL` 상수 값에 붙여넣습니다.

설정을 완료하면:
- 참가자가 정보 입력 + 동의 후 "다음"을 누르는 순간 **lead(리드) 단계**로 이름/학년/전공/이메일이 시트에 기록되고,
- 테스트를 끝까지 완료하면 같은 행이 **result(결과) 단계**로 업데이트되어 성향·직무 추천 결과까지 함께 저장됩니다.

`GOOGLE_SHEET_WEB_APP_URL`을 비워두면 기존처럼 localStorage에만 저장되고
구글 시트로는 전송되지 않습니다 (앱은 정상 동작).

## 🪪 사원증용 결과 카드 자동 저장 (기기 의존 없는 "무조건 저장")

브라우저에서 PNG를 직접 다운로드하는 기능("📥 카드 PNG로 저장" 버튼)은 카카오톡 인앱
브라우저 등 일부 환경에서 다운로드가 막힐 수 있어요. 이 문제와 무관하게 항상 데이터가
남도록, **테스트가 끝나는 순간 결과 카드 이미지를 자동으로 서버에 전송**해서:

1. 구글 드라이브의 `채용박람회 사원증 카드` 폴더에 `참가자ID.png`로 저장되고 (없으면 자동 생성),
2. `apps-script/Code.gs`의 `NOTIFY_EMAIL` 상수에 이메일을 넣어두면, 카드가 완성되는 즉시
   해당 주소로 PNG가 첨부된 메일이 자동 발송됩니다. (기본값은 `ahjung@spigen.com`으로 되어
   있으니 필요하면 바꿔주세요. 참가자가 아주 많다면 Gmail 일일 발송 한도에 걸릴 수 있어
   빈 문자열로 비워서 드라이브 폴더만 쓰는 것도 방법이에요)

이 경로는 참가자의 브라우저/기기 상태와 완전히 무관하게 동작해요 (참가자가 다운로드 버튼을
누르지 않아도, 심지어 인앱 브라우저처럼 다운로드가 막힌 환경이어도 서버로는 항상 전송됩니다).

이 기능을 처음 켤 때는 Apps Script 배포 시 **구글 드라이브·Gmail 접근 권한** 승인 팝업이 새로
뜰 수 있어요. 본인 계정으로 승인해주세요.

## ⚠️ 개인정보 수집 동의 문구에 대해

정보 입력 화면의 개인정보 수집·이용 동의 문구(`index.html`의 `CONSENT_TEXT`
상수)는 **예시 템플릿**입니다. 실제 채용박람회에서 사용하기 전에 반드시
사내 HR/법무 담당자의 검토를 받아 수집 항목, 이용 목적, 보유 기간 등을
실제 운영 정책에 맞게 수정해주세요.

## 💼 직무 추천 로직

- 밸런스 게임 문항 10개는 각 선택지마다 성향 점수(동물 캐릭터용)와
  직무 성향 점수(8개 직무 분야용)를 함께 반영합니다.
- 마지막 문항은 "가장 끌리는 직무 분야"를 직접 고르는 선택형 문항으로,
  자기 선언적 관심사에 가장 큰 가중치를 둡니다.
- 두 점수를 합산해 1순위·2순위 추천 직무를 계산합니다. (`index.html`의
  `JOB_ROLES`, `calculateJobScores`, `matchJobs` 참고)
- 기본 직무 분야 8개(마케팅/브랜드기획, 영업/해외영업, 상품기획/MD, 디자인,
  연구개발/품질, SCM·생산·물류관리, 경영지원, IT/데이터)는 일반 제조·유통사
  기준 예시이므로, 실제 채용 중인 직무에 맞게 `JOB_ROLES`와 관련 문항의
  `jobTraits` 값을 조정해 사용하세요.
